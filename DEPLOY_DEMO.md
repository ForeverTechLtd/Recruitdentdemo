# Recruitdent Demo Deployment

This folder is ready to share as a static demo. It uses demo data in the visitor's browser and is not connected to real accounts, payments, bookings, document verification or uploads.

## Recommended: Vercel

1. Create a free Vercel account at https://vercel.com.
2. Create a GitHub repository for this folder.
3. Upload or push these files to the repository.
4. In Vercel, choose **Add New Project**.
5. Import the GitHub repository.
6. Leave build settings blank/default. This is a static HTML demo.
7. Deploy.
8. Open the generated Vercel URL and check the main pages:
   - `#overview`
   - `#clinic`
   - `#clinic-profile`
   - `#professional`
   - `#marketplace`
   - `#rota`
   - `#admin`

## Sharing Text

Use this wording when sending the link:

> This is an interactive Recruitdent prototype showing proposed clinic and professional workflows. It uses demo data only and is not yet a live booking, payment or document-verification platform.

## Before Sharing

- Do not add real patient, clinic, staff or professional documents.
- Keep the visible demo banner.
- Keep `noindex` enabled so the demo is not intended for search indexing.
- Treat feedback as product discovery, not live onboarding.
